## 从本源码仓库启动

**本源码仓库不包含 Node 二进制和 node_modules。** 便携 ZIP 才包含这些环境；本仓库提供可编辑源码。将本文件夹交给具备本地执行能力的 AI 工具时，请先说明“这是源码版”。

安装 Node.js 22 或更新版本后，在项目目录执行：

```bash
npm ci --ignore-scripts
node server.mjs
```

然后打开 http://127.0.0.1:3088/control 。首次启动默认停止，不会自动请求付费模型。用户在网页填写自己的 Key，再自行点击“启动互动”。源码版不需要 Python、FFmpeg 或 DSH；包内双击脚本依赖未入库的 runtime，请使用上面的命令，或让 AI 下载校验官方 Node 后协助运行。

以下“便携版”说明仅适用于另行分发的完整运行 ZIP，不代表源码仓库自带环境。源码仓库也不包含 third-party-sources 中的大型源代码归档，来源与精确版本见该目录说明和 runtime/provenance.json。

## 费用与停止

代码和运行包免费，您的模型与语音服务按服务商规则计费。后台运行默认待机；点「启动互动」后才允许自动辩论和回复。点击「停止互动」阻止后续调用；全部控制台/有声舞台失联约20秒也会自动停止。重新打开不自动恢复。停止前已经提交的服务请求可能已计费。

本地背景音乐与模型额度无关。场景二音乐卡明确选择「当前工作台」或「直播窗口」。角色语音所有入口统一1并发排队，不代表同账号其他软件也受此队列限制。

## 直播伴侣

需要补充采集礼物时，在「工作摸鱼」或「AI 辩论赛」控制台顶部点击 **连接直播伴侣**。程序会复用已开放调试的伴侣，或以调试模式启动已安装的伴侣，再启动礼物采集器。采集器自动使用当前项目的后台地址（包括自定义 `PORT`），页面会显示连接、等待重连或端口占用状态。首次连接只记录已有礼物，连接后新出现的礼物才会处理；礼物回复需要另行点击「启动互动」。

如果伴侣已经以普通模式运行，请先下播并手动退出，再点击连接；程序不会强制退出伴侣，也不会替您开播。Mac 使用系统应用启动器打开完整 `.app`，Apple Silicon 机器使用原生启动路径，避免继承后台 Node 的 Rosetta 架构及工具环境。采集读取同一时间最多一个请求，超时后断开重连，避免伴侣繁忙时积压请求。其他项目或旧版采集器占用采集端口时会明确提示，不会自动接管。Windows调试/礼物DOM采集尚未实机验证，可能受伴侣版本限制。

便携版也可运行 **连接直播伴侣 Mac.command** 或 **连接直播伴侣 Windows.bat**。源码版命令行入口为 `node companion.mjs`；使用自定义后台端口时需同时传入 `PORT` 或完整的 `APP` 地址。

进场欢迎依赖收到真实进场事件，不能保证平台给每一位观众下发昵称。模拟进场只能验证本地欢迎队列。
